№4 зертханалық жұмыс. Беттік толқындардың таралу жылдамдығын анықтау

Мақсаты: су бетіндегі толқындардың таралу жылдамдығын өлшеу.
Секундомер: 0.00 с

Секундомер қалтқы суға түскен сәтте қосылып, толқын қарама-қарсы шетіне жеткенде тоқтайды. Бірінші тәжірибеден кейін l өзгертілмейді (4-тармақ: тәжірибені 5 рет қайталаңдар). Өзгерту үшін «Қайта бастау» батырмасын басыңыз.

№ р/сӨлшеу нәтижелеріЕсептеу нәтижесі (өзіңіз есептеңіз)
Уақыт t, сЫдыстың (кюветаның) ұзындығы l, мТолқынның жылдамдығы υ, м/с

Формула: υ = l / t. Нәтижені 3 таңбаға дейін дөңгелектеңіз. Үтір немесе нүктені қолдануға болады.

Қателікті бағалау (6–8 тармақтар)
υорт = (υ₁ + υ₂ + υ₃ + υ₄ + υ₅) / 5 = м/с
Орташа квадраттық ауытқу S = м/с
Стьюдент коэффициенті t = (α = 0,95, n = 5 үшін №1 зертханалық жұмыстан алыңыз)
Абсолют қателік Δυорт = м/с
Салыстырмалы қателік ε = Δυорт / υорт · 100% = %
Жауап: υ = ± м/с, ε = %
Батырма тек ✓ немесе ✗ көрсетеді, дұрыс жауапты көрсетпейді.
